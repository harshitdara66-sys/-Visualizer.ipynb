# COVID-19 Data Analysis & Visualization

## Overview
This project contains a Jupyter Notebook (`Visualizer.ipynb`) that performs exploratory data analysis (EDA), data cleaning, feature engineering, aggregation, and visualization on a COVID-19 dataset using Python.

## Features
- Dataset import and inspection
- High-level data understanding
- Low-level data exploration
- Data filtering operations
- Data cleaning and preprocessing
- Date & time formatting
- Data aggregation and grouping
- Feature engineering
- Data visualization using charts and graphs

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook


## Analysis Workflow

### 1. Import Dataset
Load the COVID-19 dataset into a Pandas DataFrame.

### 2. High-Level Data Understanding
- Dataset dimensions
- Column information
- Data types
- General overview

### 3. Low-Level Data Understanding
- Unique values
- Descriptive statistics
- Detailed column analysis

### 4. Data Filtering
Apply conditions and filters to extract meaningful insights.

### 5. Data Cleaning
- Handle missing values
- Remove inconsistencies
- Improve data quality

### 6. Date-Time Formatting
Convert and process date-related fields for analysis.

### 7. Data Aggregation
Use grouping and aggregation techniques to summarize data.

### 8. Feature Engineering
Create derived columns and additional analytical features.

### 9. Data Visualization
Generate visual insights using:
- Line Charts
- Bar Charts
- Distribution Plots
- Comparative Visualizations
